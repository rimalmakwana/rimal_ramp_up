A . What's the difference between let, const, and var? Which one would you use by default and why?

var :

    - var is function scope and non-block scope variable. 

    - support a reassignment and redeclaration.

let :

    - let is block scope

- support a reassignment and not support a redeclaration.

const :

    - const is block scope.

    - not support a reassignment and redeclaration.


- use a const as a by default because Prevents accidental changes and Makes code safer & predictable.
