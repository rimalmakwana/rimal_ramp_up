A . What is a React component in your own words? How is it different from a plain JavaScript function?

--> react component is reusable block of code it is use for the build the UI.

-- once component defined and use it multiple times any where just import it.

difference btw plain js function is :

- Component → used to build UI and JS function → used for logic

-Component → returns JSX (HTML-like UI)
JS function → returns any value (number, string)

-Component → can use state (useState) and hooks
JS function → no built-in state management

-Component → used like <MyComponent />
JS function → called like myFunction()
