B. A user fills out a form perfectly and hits submit. Your validation says everything is fine. The API returns a 400 error saying "email 
already taken." How would you show that error to the user?

- Even if frontend validation passes, backend can fail.

Store API error in state:
const [apiError, setApiError] = useState("");

On submit:
try {
  await apiCall();
} catch (err) {
  setApiError("Email already taken");
}


Show in UI:
{apiError && <p className="error">{apiError}</p>}
