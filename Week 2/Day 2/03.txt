1. This component is supposed to fetch a list of users once on load. Instead, it fetches in an infinite loop, crashing the browser. Find and fix it.

function UserList() {
  const [users, setUsers] = useState([]);

  useEffect(() => {
    fetch('https://jsonplaceholder.typicode.com/users')
      .then(r => r.json())
      .then(data => setUsers(data));
  }, [users]); // ← the developer put this here "to keep it fresh"

  return (
    <ul>
      {users.map(u => <li key={u.id}>{u.name}</li>)}
    </ul>
  );
}


answer:
-------

- because of this  [users] dependency , Run this effect every time whene  users changes

If you only want to fetch once when the component loads, use an empty dependency array:

useEffect(() => {
  fetch('https://jsonplaceholder.typicode.com/users')
    .then(r => r.json())
    .then(data => setUsers(data));
}, []); // run only once on mount
