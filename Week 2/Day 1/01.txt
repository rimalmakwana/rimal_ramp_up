1. Below is "old-style" JavaScript. Rewrite every line using modern syntax — destructuring, spread, and rest. Don't change what the code does
only how it's written.

// 1. Extracting values from objects
const name = user.name;
const age = user.age;
const city = user.address.city;

answer:

const {name , age , address:{city}} = user;

This is called object destructuring in JavaScript.

{ name, age } → basic object destructuring

address: { city } → nested destructuring

// 5. Function that accepts an object, uses name + email
function greet(user) {
  return "Hello " + user.name + ", your email is " + user.email;
}

answer:

// using parameter destructuring + template literals

function greet({name, email}){
    return `Hello ${name} , your email is ${email}`;
